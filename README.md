# HR Analytics Using SQL (MySQL)

## Project Overview
This project focuses on analyzing employee data using MySQL to understand workforce distribution, hiring trends, salary patterns, attendance, leave records, employee performance, attrition, and recruitment activities.

The project includes 71 business-oriented SQL questions covering different aspects of HR analytics.

## Database Structure
The project uses the following tables:
- Departments
- Jobs
- Employees
- Salary
- Attendance
- Leave
- Performance
- Exits
- Recruitment

## Project Objectives
- Analyze workforce distribution across departments, locations, and employment status.
- Identify hiring trends and recruitment patterns.
- Analyze salary distribution across departments and job roles.
- Evaluate employee attendance and leave patterns.
- Examine employee performance ratings.
- Calculate employee attrition and exit trends.
- Analyze recruitment activities and hiring conversion rates.

## SQL Concepts Used
- DDL, DML and DQL
- SELECT, WHERE and ORDER BY
- Aggregate Functions
- GROUP BY and HAVING
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- CASE Statements
- Date and String Functions
- Window Functions
- Views

## Tools & Technologies
- Database: MySQL
- SQL Editor: MySQL Workbench
- Version Control: Git and GitHub

## Repository Contents
- `HR-analysis.sql` – Database creation, table definitions, and SQL queries for HR analysis.

## How to Run the Project
1. Download or clone this repository.
2. Open MySQL Workbench.
3. Open the `HR-analysis.sql` file.
4. Execute the database and table creation statements.
5. Load the required HR datasets into the corresponding tables.
6. Execute the SQL queries to explore the HR analysis.

## Key Learning Outcomes
- Practiced SQL querying and relational database operations.
- Applied joins, subqueries, and CTEs to analyze employee data.
- Used aggregate functions and filtering for business reporting.
- Developed analytical problem-solving skills using MySQL.
